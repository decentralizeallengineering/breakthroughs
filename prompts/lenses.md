# Lenses

One lens per hot worker. Each line starting with "- " is one lens, in the form `name: instruction`.
Workers are given distinct lenses in this order, so the first 10 are always used when 10 workers run.

- delete-half: Delete half of the system. Which half could go, and what still works without it?
- steal-from-another-field: Steal a solution from an unrelated field (logistics, biology, finance, games, aviation, medicine) and apply it here.
- ten-x-cheaper: Make it 10x cheaper in money, time or compute. Drop whatever you must to get there.
- invert-architecture: Invert the architecture. Push becomes pull, central becomes local, synchronous becomes batch, or the reverse.
- hacker: Think like a hacker who wants the goal by the shortest path and does not care how it is meant to be used.
- hardware-differently: Use the hardware differently. Idle machines, GPUs, disks, caches, schedules, or a cheaper box.
- no-code: Reach the goal with no new code at all: configuration, a shell one-liner, a spreadsheet, a convention, a checklist.
- existing-open-source: Reach the goal with an existing open-source tool that already does most of it.
- change-workflow: Change the user's workflow instead of the software. What would the user do differently so the problem disappears?
- absurd: Propose the absurd idea that might actually work. The sillier it sounds, the more welcome it is.
